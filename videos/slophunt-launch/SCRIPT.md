# Frame 1 — Hook

Every launch page tells you your project is brilliant. None of them have read your commit history.

# Frame 2 — Problem

Product Hunt is a hype machine. Congratulations, rocket emoji. Nobody mentions the demo link died fourteen months ago.

# Frame 3 — How it works

So we built the opposite. Paste a GitHub URL. Four agents read your README, your last hundred commits, and the rest of the internet — all at once.

# Frame 4 — The score

Thirty seconds later, a Slop Score out of a hundred. Five sub-scores, computed from dates and counts. Not vibes.

# Frame 5 — The evidence

Every line cites evidence. The commit that just says fix. The dead demo. The three projects that already do this.

# Frame 6 — The video

Then it writes a vertical video roast, and ranks you in public.

# Frame 7 — Call to action

SlopHunt. Submit your repo. Get roasted. Get ranked.
